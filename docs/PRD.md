# 产品需求文档（PRD）

## 1. 文档信息

- 产品名称：诗意 · 比赛战绩统计系统
- 英文名称：Poetic Tournament Results System
- 文档版本：1.1
- 适用版本：v0.3.0 及以上
- 产品形态：本地优先的静态 Web 应用 / PWA
- 默认语言：简体中文
- 支持语言：简体中文、英文

## 2. 产品定位

本产品面向小型牌类、桌游、校园赛事、俱乐部联赛和内部竞技赛，提供报名、分组、配对、录分、排名、弃赛处理、备份和导出的一体化工具。

产品坚持本地优先：无需注册、无需后端、无需联网即可完成核心比赛流程。比赛数据优先保存在浏览器 IndexedDB，localStorage 作为兼容回退；用户可通过 JSON 文件跨设备迁移。

## 3. 目标与非目标

### 3.1 产品目标

- 降低赛事组织者的手工记录成本。
- 让配对、排名和小分计算过程可复核。
- 覆盖现场比赛常见的多小组、轮空、弃赛和加赛场景。
- 支持浏览器离线使用和 GitHub Pages 静态部署。
- 保持中英文界面一致，方便公开传播和二次开发。

### 3.2 非目标

- 不提供在线账号和云端赛事同步。
- 不替代官方赛事系统中的裁判权限和身份认证。
- 不保证算法覆盖所有地区、所有组织的官方规则。
- 不面向超大型公开赛事提供实时多人协作编辑。

## 4. 用户角色

| 角色 | 使用方式 | 主要诉求 |
|------|----------|----------|
| 比赛组织者 | 浏览器直接使用 | 创建赛事、管理名单、配置赛制、控制进度 |
| 裁判 / 赛务人员 | 浏览器直接使用 | 录入赛果、处理弃赛、核对排名和导出结果 |
| 参赛选手 / 观众 | 查看当前页面 | 查看对阵、战绩、排名和比赛状态 |
| 二次开发者 | 克隆仓库并部署 | 扩展赛制、统计指标或部署到自有平台 |

当前版本是单浏览器本地应用，不区分登录身份和细粒度权限。

## 5. 核心使用场景

### 5.1 创建并启动赛事

1. 设置赛事名称、小组数量、每组人数、轮次、局制和配对方式。
2. 手动录入、文本粘贴或从 Excel / CSV / TXT 导入选手。
3. 使用整体预览检测重名和空小组。
4. 启动当前小组或全部小组。

### 5.2 单轮比赛流程

1. 系统生成首轮或下一轮对阵。
2. 组织者录入每场胜负、比分、双负或赛前弃赛。
3. 当前轮全部完成后解锁下一轮。
4. 系统实时重算排名、小分和淘汰状态。
5. 每轮完赛自动创建快照。

### 5.3 修正与恢复

1. 使用撤回上一轮恢复对阵和选手状态。
2. 使用 Ctrl/Cmd + Z 触发快捷撤回。
3. 在备份管理器中恢复或删除历史快照。
4. 导出 JSON 作为跨设备或长期备份。

### 5.4 导出与发布

1. 排行榜、对阵表或总表可导出为 Excel。
2. 排行榜和对阵表可导出为 PNG。
3. 所有小组数据可批量导出。
4. 应用可安装为 PWA，并在离线状态下打开已缓存资源。

## 6. 功能需求

### 6.1 赛事与小组

- 支持 1-20 个小组。
- 支持小组新增、删除、重命名和切换。
- 支持单组独立开赛和全部小组同时开赛。
- 支持瑞士轮和单败淘汰。
- 支持 BO1、BO3、BO5、BO7。
- 单败淘汰支持每轮独立设置局制。
- 赛事开始后禁止调整小组数量，避免破坏已有赛程。

### 6.2 选手管理

- 支持添加、编辑和删除选手。
- 支持文本换行、逗号、分号和制表符分隔。
- 支持 `.xlsx`、`.xls`、`.csv`、`.txt` 导入。
- 多 Sheet 工作簿按 Sheet 名创建或映射小组。
- 支持自动识别姓名列和手动选择表头。
- 自动过滤空值、重复项、表头字段和明显非姓名内容。
- 支持选手整体预览、搜索、复制、重名提示和空组提示。

### 6.3 配对

- 瑞士轮首轮随机配对。
- 后续轮次按战绩组、对折、穷举和上下移组规则配对。
- 同赛事内避免重复对阵。
- 支持轮空、弃赛和加赛场景。
- 单败淘汰按胜者晋级、败者出局。
- 单败淘汰当前轮支持整轮编辑、随机分配和按录入顺序分配。

### 6.4 结果录入

- 支持左胜、右胜、双负、具体比分和重置。
- 支持赛前弃赛：对方获胜，弃赛者不记败场，该场不进入对手胜率网络。
- 支持赛后弃赛：不产生新胜负，仅退出后续配对。
- 支持撤回上一轮。
- 支持测试模式随机生成当前轮或整场结果。

### 6.5 排名与统计

- 瑞士轮按活跃状态、胜场、对手胜率、局胜率等指标排序。
- BO1 使用 SOS、SOSOS 等破分指标。
- BO3+ 使用本人局胜率和对手局胜率。
- 单败淘汰按淘汰轮次、胜场、败场和姓名排序。
- 支持冠军、亚军、四强、八强等头衔。
- 支持平分检测和加赛。
- 加赛只用于区分名次，不计入常规小分。

### 6.6 国际化与文本

- 所有核心页面支持中英文切换。
- 语言偏好保存在 localStorage。
- 文案统一维护在 `src/i18n/data.ts`。
- 自动检查中英文键、占位符和空值一致性。
- 日期、时间和分隔符根据语言显示。

### 6.7 数据、备份和导出

- IndexedDB 作为赛事主存储。
- localStorage 作为兼容镜像和小数据回退。
- 主数据和备份数据分离保存。
- 数据写入串行化，避免旧请求覆盖新请求。
- 导入和加载时进行 Schema 校验。
- 支持最多 5 份自动快照。
- 支持 JSON 导入导出、Excel 导出和 PNG 导出。
- 支持跨标签页同步；同时写入时显示冲突提示。

### 6.8 PWA 与离线

- 提供 SVG favicon、Apple Touch Icon、192 和 512 图标。
- 提供 Web App Manifest。
- 使用 Workbox Service Worker 预缓存应用资源。
- 支持离线打开、自动更新和缓存清理。

## 7. 页面与信息架构

### 7.1 主页面

- 顶部：标题、状态、轮次、选手数、已完成场次、保存时间。
- 小组切换栏。
- 左侧：排名和比赛历史。
- 中间：轮次标签、对阵列表、结果录入。
- 右侧：赛事设置、小组管理、赛制、选手管理、比赛控制。
- 顶部工具栏：语言、帮助、测试模式、选手预览、图片导出、Excel 导出。

### 7.2 弹窗与独立页面

- 确认弹窗：生成下一轮、撤回、重置、删除和加赛清除。
- 选手预览弹窗。
- Excel 和图片导出弹窗。
- 备份管理器。
- 帮助与规则页面。
- 全局错误边界页面。

## 8. 非功能需求

### 8.1 性能

- 首屏主包 gzip 目标不超过 90KB。
- 最大单资源 gzip 目标不超过 180KB。
- 总资源 gzip 目标不超过 420KB。
- Excel 大量数据解析和生成在 Web Worker 中执行。

### 8.2 可靠性

- 存储写入必须串行。
- 导入数据必须通过 Schema 校验。
- 主存储不可用时尝试备份数据。
- 离线状态下已缓存页面仍可打开。

### 8.3 可维护性

- TypeScript 使用严格模式。
- 组件、国际化、Store Actions、存储、导入和导出按领域分目录。
- 业务规则优先写成纯函数并配单元测试。
- CI 必须通过类型检查、Lint、测试、构建、浏览器测试和离线测试。

### 8.4 安全

- 使用维护中的依赖版本。
- `npm audit` 必须为 0 漏洞。
- 不在前端保存账号、密钥或服务端令牌。
- 导入文件需防止损坏数据和异常输入进入赛事状态。

## 9. 验收标准

- 可完成“创建赛事 → 导入选手 → 开赛 → 录分 → 下一轮 → 导出”的完整流程。
- 中英文切换后，核心页面无混用文案。
- 刷新或重新打开浏览器后，赛事数据可恢复。
- 断网后刷新，已安装或已访问的页面可离线打开。
- 导入非法 JSON 或非法 Excel 结构时给出明确错误，不破坏当前数据。
- 主分支 CI 和 GitHub Pages 部署均成功。

## 10. 后续路线

- 自定义破分指标和规则模板。
- 双败淘汰、循环赛和团体赛。
- 操作审计与结果修改记录。
- 更完整的多标签页协作和冲突合并。
- 公开只读战绩页和分享链接。
- 打印布局和赛事报告导出。
